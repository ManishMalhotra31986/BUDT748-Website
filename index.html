What This Project Covers

This site was designed in Figma and then rebuilt with HTML, CSS, and Bootstrap for the BUDT748 client side technologies assignment.

01

Figma Design

Three desktop frames built at 1440 × 1024 on a 12 column grid, using a dark navy palette and Montserrat typography.

02

HTML & CSS

Semantic HTML structure paired with a custom stylesheet that defines the color tokens, spacing, and hover interactions.

03

Bootstrap 5

A responsive collapsing navbar, the 12 column grid system, styled buttons, and form components pulled in from the CDN.

BUDT748 at a Glance
