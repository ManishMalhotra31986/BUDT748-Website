BUDT748 — INFORMATION SYSTEMS

The client side technologies course for Information Systems students at the Robert H. Smith School of Business.

About the Course

BUDT748 teaches the technologies that run in the browser. Students learn how a design moves from an idea, into a wireframe or mockup, and finally into working code that anyone can open on the web.

The course walks through designing an interface in Figma, converting that design into structured HTML, styling it with CSS, making it responsive with the Bootstrap framework, and publishing the finished result to a live host such as GitHub Pages.

This website is my submission for that project. Every page was first laid out in Figma on a 1440 × 1024 desktop frame using a 12 column grid, then rebuilt by hand in HTML and CSS with Bootstrap handling the responsive behavior.
